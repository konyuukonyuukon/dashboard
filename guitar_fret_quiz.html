🔑 曲の「キー」って何で決まるの?

キー(調)とは、その曲の「基準になる音(トニック)」と、そこから作られるスケールのことです。キーが分かると、その曲でどの音・どのコードが使われやすいかが見えてきます。

キーを見分けるには、次のポイントをチェックします:

  • 曲の最後に落ち着く音・コード — 曲が「終わった!」と感じる音は、多くの場合そのキーのトニック(1度)です
  • 使われている音の集まり — 出てくる音を集めて、どのメジャー/マイナースケールに当てはまるかを調べる
  • 「帰ってきた」感のある進行 — ドミナント(V)からトニック(I)に戻る進行(V→I)は、キーを強く感じさせる場所
  • 楽譜の調号 — ♯や♭の数を見れば、五線譜ではキーがすぐ分かる
💡 例: C → Am → F → G → C という進行が繰り返される曲は、Cで始まり、Gから戻ってCで落ち着く。この場合は「Cメジャーキー」の可能性が高いです。
📏 度数(なんど)ってなに?

度数は、基準の音(1度）から数えて「何番目の音か」を表す数え方です。キーが決まれば、そのキーのスケールの中で各音に番号(度数)がつきます。

例えば Cメジャーキー なら:

音CDEFGAB
度数1度2度3度4度5度6度7度

コードの構成音も度数で表せます:

  • メジャーコード = 1度 + 3度 + 5度（例: C = C・E・G）
  • マイナーコード = 1度 + ♭3度 + 5度（例: Cm = C・E♭・G）
  • セブンスコード = 1度 + 3度 + 5度 + ♭7度（例: C7 = C・E・G・B♭）
🎼 キーの中の度数でコードの役割が決まる

キーのスケール上の音をそれぞれルートにしてコードを作ると、7つのコードができます。これをダイアトニックコードと呼び、ローマ数字（I II III…）で表します。

中でも特に大事なのが I・IV・V の3つの役割です:

  • I トニック — 曲の「家」。一番安定していて、落ち着く響き
  • IV サブドミナント — 「外出」。少し動き出す、やわらかい響き
  • V ドミナント — 「帰りたくなる」。不安定で、次に I に戻りたくなる緊張感

Cメジャーキーの場合のダイアトニックコード:

度数ローマ数字コード役割
1度ICトニック（安定）
2度iiDmサブドミナント寄り
3度iiiEmトニック寄り
4度IVFサブドミナント（やわらか）
5度VGドミナント（緊張）
6度viAmトニック寄り
7度vii°Bdimドミナント寄り（不安定）
💡 有名な「王道進行」や「カノン進行」も、このローマ数字（I-V-vi-IV など）の組み合わせで説明できます。キーが変わっても、ローマ数字の関係性は同じまま平行移動するのがポイントです。
